Quiero que me desarrolles un juego de serpiente en la carpeta 2doParcial con el pryecto JuegoSerpiente, en react y typeScript. El juego debe representar el tablero como una matriz  o tabla  HTML y permitir que la persona controle la sepiente mediante el teclado. El proyecto debe estar creado como una aplicacion nueva con vite, react y typeScript.
*Las regas del juego*
1.El tablero debe tener 8 filas y 8 columnas
2.La serpiente debe comenzar con tres segmentos
3. La Cabeza  debe identificarse claramente con el resto del cuerpo.
4. Cada pulsacion de una flecha debe representar un turno.
5.En cada turno , la cabeza debe avanzar una celda en la direccion indicada.
6. El cuerpo  debe seguir  a la cabeza;  si no com, debe eliminarse el ultimo segmento.
7.La comida debe  aparecer en una celda que no este ocupada por la serpiente.
8.Cuando la cabeza llega a la comida, la serpiente debe crecer en un segmento.
9. El juego debe terminar cuando la serpiente salga del tablero o choque con su propio cuerpo.
10. El estado del juego debe actualizarse  y el tablero debe volver a renderizarse despues de cada turno.
11. Cuando el juego termine, debe existir una señal visual. Por ejemplo, en el ejemplo que el borde externo de la tabla cambia de color a rojo cuando ocurre una colison o a verde si ganaste el juego.
En este fragmento se muestra una forma de reconocer la tecla presionada, adaptala para actualizar el estado del juego:

import type {keyboardEvent} from 'react';
const manejarTecla = (event: keyboardEvent<HTMLDivElement) => {
  if (event.key === 'ArrowUp') {
    console.log('Arriba');
  } else if (event.key === 'ArrowDown') {
    console.log('Abajo');
  } else if (event.key === 'ArrowLeft') {
    console.log('Izquierda');
  } else if (event.key === 'ArrowRight') {
    console.log('Derecha');
  }
};
 return (
  <div tabIndex={0} onKeyDown={manejarTecla}>
    {/* tablero*/}
  </div>
);
